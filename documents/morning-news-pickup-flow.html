morning-news-pickup フロー図

1. URLを開いてから表示されるまで

ログイン判定 → 画面表示 → API → 1日1回の取得判定

flowchart TD
  A["ブラウザで / を開く"] --> B{"ログイン済み？
SecurityConfig・30日保持"}
  B -- いいえ --> L["ログイン画面 login.html
パスワードだけ入力（ユーザー名 owner は自動送信）"]
  L -- "POST /login 成功で元のURLへ" --> C
  B -- はい --> C["index.html を返す
Vue画面（App.vue）"]
  C --> D["App.vue がAPIを呼ぶ
GET /api/news
更新ボタンは POST /api/news/refresh"]
  D --> E["NewsController"]
  E --> F{"今日（日本時間）取得済み？
更新ボタンのときは取り直す"}
  F -- はい --> G["保持した結果を使う"]
  F -- いいえ --> H["全ジャンルを取得し直す
NewsService.loadAll → RssFetcher"]
  G --> J["JSONを返す → タブ・カードで表示
国内の時事 / 経済・ビジネス / IT・テック"]
  H --> J

2. 取得元（カード1枚）ごとの処理 NewsService.load

「全ジャンルを取得し直す」の中で、取得元ごとに行う処理

flowchart TD
  S1["RSSを取得して読み取る
RssFetcher"] --> S2["期間で絞り込む
24時間（Yahoo!は絞らない）"]

ブクマ数順（はてな） / RSSの順（Yahoo!・Zenn・Qiita）"]

足りないとき「◯件のみ表示」"]
  S4 --> R["カード1枚分の結果
SourceResult"]
  S1 -. 途中で例外 .-> E1["「取得に失敗しました」

  E1 --> R
